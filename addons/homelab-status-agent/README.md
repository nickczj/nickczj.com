# Homelab Status Agent

Home Assistant local add-on for pushing Home Assistant Yellow node KPIs to `nickczj.com`.

This add-on reports CPU, memory, load, uptime, temperature when exposed by HAOS, and the local Tailscale add-on state from Supervisor. It does not inspect Docker, Home Assistant Core, Zigbee, or other services.

See `DOCS.md` for setup instructions.
